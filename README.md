# CAMELS daily streamflow benchmark: Mamba-3 vs CuDNN LSTM

Code for the manuscript *Who remembers the rain? A matched benchmark of Mamba-3 and LSTM for daily streamflow*.

This repository contains the training, evaluation, tuning and analysis code. It does **not** contain the CAMELS data, model checkpoints, or run outputs.

## Contents

| Path | What it is |
|---|---|
| `src/` | training, evaluation, tuning, figures, tables and audits |
| `scripts/` | batch runners and checks |
| `tests/` | unit tests |
| `recipes/` | locked recipes, HPO grids and the evaluation manifest |

## Data

Download CAMELS v1.2 (RAL v2.0) from the NCAR archive (Zenodo record 15529996) and use the Daymet forcing. The record spans 1980-10-01 to 2014-09-30.

The split is fixed in `data/split.json` with SHA-256:

```
9efbe60e790965f203b037d7e630828f7fe36285d4c86ee5c3ddbd93ec13cc58
```

Do not regenerate the split. Run:

```bash
python src/data_utils.py --build
python src/data_utils.py --split
```

`--build` downloads the CAMELS v1.2 archive and attribute tables, checks their SHA-256, extracts them, and writes the arrays. `--split` writes the pickles and the split specification. Allow about 20 GB of free disk space. The arrays and pickles are ignored by git.

## Environment

The reported runs used:

- Python 3.13.18
- PyTorch 2.13.0+cu130
- CUDA 13.0
- numpy 2.5.4
- pandas 3.1.0
- mamba-ssm 2.3.2.post1
- causal-conv1d 1.7.0
- one NVIDIA GeForce RTX 4060 Laptop GPU (8 GB)

Install the Python packages:

```bash
pip install -r requirements.txt
```

HydroDL (MHPI) is required for the CuDNN LSTM wrapper. It is not on PyPI:

```bash
pip install git+https://github.com/mhpi/hydroDL.git
```

## Protocol

Three stages, one direction: train, validation (many times), test (once per registered cell).

```bash
# Train one cell and score validation every epoch.
python src/train_val.py --model lstm --tier 1 --depth 1 --epochs 60 --seed 1 --config recipes/lstm.json

# Tune on validation only. The driver calls train_val.py.
python src/hpo.py recipes/sweeps/matched.json

# Evaluate the test cells listed in recipes/eval_manifest.json.
python src/run_test_all.py --dry-run
python src/run_test_all.py
```

`train_val.py` never opens the test slice. `eval_test.py` is the only script that passes `allow_test=True`.

## Determinism

The LSTM is bitwise reproducible on one machine for a fixed seed. Mamba-3 is not, because its fused kernels are not deterministic. Report the seed count, not a single run.

## Outputs

`output/`, `results/`, `figures/`, `logs/` and `archive/` are ignored. They are regenerated by the code. The manuscript tables come from `src/make_tables.py` and `src/stats_multiseed.py`.
